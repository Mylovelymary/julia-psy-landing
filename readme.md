Шаг 1: Подготовка окружения
Делаем всё по уму, чтобы не засорять глобальный Python. Создаем и активируем виртуальное окружение:

Bash
python3 -m venv venv
source venv/bin/activate
(Слева в терминале должна появиться приписка (venv)).

Шаг 2: Установка библиотеки
Нам нужен aiogram третьей версии. Устанавливаем:

Bash
pip install aiogram
Шаг 3: Запуск
Когда установка закончится, стартуем нашего бота:

Bash
python3 bot.py
Если всё сделано верно, в терминале появится надпись INFO:aiogram.dispatcher:Start polling и Бот запущен!.
